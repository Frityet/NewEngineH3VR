# Native video adapter

`platform/video/build.sh [retargeted-Game.dll]` builds `NativeH3VR.Platform.dll` and a patched copy of the supplied Game DLL under `build/video/managed/`. The original AVPro factory creates `UnityMediaPlayer`, which uses Unity VideoPlayer's native macOS decoder and texture output. Original AVPro consumers, events, materials, track interfaces, and sideloaded subtitles remain in place. Windows platform shutdown and DOS8.3 path conversion are removed from the reachable native path.

The adapter exposes Unity VideoPlayer's decoded PCM through `AudioSampleProvider` in `APIOnly` mode. This feeds the original AVPro `AudioOutput.OnAudioFilterRead` → `AudioOutputManager` → `GrabAudio` consumer on Unity's audio thread. The callback uses a bounded, synchronized PCM ring, rate conversion, channel conversion and cached playback state; pause and seek flush queued samples. A native Unity 2021.3.45f2 ARM64 proof using the normal `MediaPlayer.OpenMedia` wrapper passed real independent stereo media through the AVPro output, paused silence, paused seek/resume, two simultaneous players, dispose and reopen. Receipt: `audio-candidate/output/grabaudio-result-2021-wrapper.json`; the paired game/backend binaries and hashes are recorded in `audio-candidate/output/wrapper-pair-sha256.txt`.

All 67 recovered MediaPlayer components use `useUnityAudio: 0` and all 67 have linked AVPro AudioOutput components configured for multiple channels, matching the adapter's PCM route. The 18 shipped TutorialVideo MP4s inspected are AAC stereo at 48 kHz; the proof fixture's provider and Unity output were also 48 kHz. Unsupported byte offsets and custom HTTP headers explicitly fail to open. The adapter does not claim embedded subtitle extraction, AVPro buffered-frame synchronization, custom audio360/head-focused rendering, or DRM features that Unity VideoPlayer does not expose. Those remain gaps if a gameplay path requires them.

The backend and player patch compile against the locally extracted ARM64 Unity 2021.3.45f2 macOS player modules. Runtime evidence is produced by `../probe-unity/` for video and the preserved native audio-candidate fixture for AVPro PCM. Successful compilation alone does not establish decoding or texture orientation.
