# Native shader recovery — 22 October 2026

**Corrected semantic recovery:** the shared exporter preserves texture-resource/sampler identity, signed immediate offsets, texture-result channel mapping, and proven DXBC predicate masks. Metadata-based shadow texture declarations are restored. The frozen 277-object re-export preserves 124 public/manual sources and regenerates 153 recovered sources. Both native ARM64 Metal gates passed: 32,846 exact manifest draws and 5,696 retention callbacks with no missing variants or raw compiler/pipeline diagnostics. The declaration-only export changes 4,994 declaration blocks and no instruction bodies (`semantic-v2-declaration-only-proof.json`). All 44 remaining flat recovered objects have no original mono stage alternatives (`semantic-v2-residual-coverage.json`). These execution/retention proofs do not establish universal arithmetic or Windows pixel equivalence. The independent FinalPass oracle covers 144 deterministic comparisons against historical source, with maximum channel error below 1/255; its regenerated bytes and metrics are unchanged. See `finalpass-regenerated-oracle-verification.json`, `semantic-optics-execution-proof.json`, and `semantic-materials-execution-proof.json`. Only the hash-pinned snapshot is eligible for final staging; its staging receipt records the actual checkpoint.


This is a working shader port, not proof of full H3VR rendering parity. Original Steam data and `recovered/ExportedProject` remain unchanged.

## Runtime pipeline repairs

The first actual game boot exposed missing interpolators that editor import and SetPass had not reported. The original legacy decompiler overwrote output metadata when a DXBC register packed two semantics into `.xy` and `.zw`. The exporter now evaluates the original instruction once into a temporary and distributes each written lane to the appropriate semantic. Cross-semantic input vectors preserve their original component ordering as well. This restored 31 shader files, including Bloom, Uber and WFX. Source changes are in the consolidated exporter patch; `packed-io-probe-changes.json` lists the affected files.

Unity 2020 Metal code generation also produced an invalid scalar/vector `bitFieldInsert` overload from stereo matrix row arithmetic. `repair_stereo_matrix_indices.py` simplifies only indices proven within a straight-line block to derive from `unity_StereoEyeIndex << 2`: `(eye * 4 + row) / 4` for row 0–3 becomes `eye`. It stops propagation when the register is rewritten or a block ends. 496 indices in 21 sources were repaired.

Metal BGRA targets reject three-component fragment color outputs. Three laser copies now emit float4 with additive alpha zero, retaining the original RGB calculation and destination alpha. Night-vision NVGBLUR also emits float4; its original ColorMask RGB remains in place. The eight PIP postprocess passes were originally tagged META and stripped from the Unity 2020 player, although original `PIPScope.cs` explicitly invokes them with Graphics.Blit pass indices 0–7. Their tags now say Always so they survive the player build. `metal-runtime-source-repairs.json` records these changes.

`NativePipelineProbe.app` is an ARM64 player that draws every exposed pass of every recovered shader with command buffers and readback, including required structured-buffer bindings. This checks actual Metal render-pipeline creation rather than relying on import support flags. It also reruns the quantitative histogram/trail/stencil checks. Main-source changes are recorded in `staged-runtime-pipeline-fixes.json`. Full appearance, nondefault keyword paths and scene-level VR parity remain unproven.

`validated-runtime-sources` pins the 277 source files used by the passing native runtime sweep. Subsequent experiments in `shader-probe` do not modify that snapshot; full-graph restaging uses the pinned sources.

Passing final native sweep evidence: `native-pipeline-summary.json`, `native-pipeline-report.json`, and `native-pipeline-verified-runtime.log`: 277 supported shaders, 1,114 drawn passes, zero pipeline errors, zero skipped draws and zero exceptions. Quantitative GPU tests also pass.
